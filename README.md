# Developer Portfolio

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen?style=for-the-badge)](https://harshvardhanhv.github.io/dev-portfolio-v1/)

[![GitHub](https://img.shields.io/badge/GitHub-Repository-black?style=for-the-badge&logo=github)](https://github.com/HarshVardhanHV/dev-portfolio-v1)

A responsive personal developer portfolio built using HTML5, CSS3, and JavaScript.

## Features

- Hero section
- About section
- Skills section
- Tech Stack section
- Projects section
- Contact form UI
- Dark/Light mode
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Folder Structure

```
dev-portfolio-v1/
├── assets/
├── css/
│   └── style.css
├── js/
│   └── script.js
├── index.html
├── README.md
├── CONTRIBUTING.md
├── CHANGELOG.md
└── .gitignore
```

## Setup

1. Clone the repository.
2. Open the project folder.
3. Launch `index.html` in a web browser.
